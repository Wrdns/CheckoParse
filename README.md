## Демка без апи ключа


```sh
php -S 127.0.0.1:8080 -t public examples/demo.php
```

Откройте [Swagger UI](http://127.0.0.1:8080/docs). Разверните метод, нажмите **Try it out**, оставьте предложенный ИНН и нажмите **Execute**.
Демо читает два файла из `examples/responses/` и помечает ответы заголовком `X-Data-Source: demo`. Карточка ООО «1С-СТАРТ» содержит поля из опубликованного образца Checko. Карточка ИП учебная. Для других корректных ИНН демо возвращает `404`. ## Запуск с данными Checko

```powershell
$env:CHECKO_API_KEY = Read-Host 'Ключ Checko' -MaskInput
php -S 127.0.0.1:8080 -t public public/index.php
```

В Bash можно запустить сервис так.

```bash
read -rsp 'Ключ Checko: ' CHECKO_API_KEY && echo
export CHECKO_API_KEY
php -S 127.0.0.1:8080 -t public public/index.php
```

| Переменная окружения | Назначение |
| --- | --- |
| `CHECKO_API_KEY` | Ключ поставщика |
| `APP_API_TOKEN` | Если задан, оба метода получения карточек требуют заголовок `Authorization: Bearer <токен>`. |
| `CHECKO_CACHE` | Значение `1` включает кэш положительных ответов на 300 секунд. Нужны расширение `pdo_sqlite` и доступ PHP на запись в `var/`. По умолчанию кэш выключен. |

## Запрос и ответ

| Метод и путь | Результат |
| --- | --- |
| `GET /api/v1/companies/{inn}` | Карточка организации по десятизначному ИНН |
| `GET /api/v1/entrepreneurs/{inn}` | Карточка ИП по двенадцатизначному ИНН |
| `GET /health` | Публичная проверка  ответа приложения. Возвращает `{"status":"ok"}` |

Например, запрос к демосерверу

```sh
curl http://127.0.0.1:8080/api/v1/companies/7735560386
```

возвращает HTTP 200 и карточку организации.

```json
{
  "data": {
    "inn": "7735560386",
    "ogrn": "1097746328360",
    "name": "ОБЩЕСТВО С ОГРАНИЧЕННОЙ ОТВЕТСТВЕННОСТЬЮ \"1С-СТАРТ\"",
    "status": "Действует",
    "registered_at": "2009-06-03",
    "address": "124482, г. Москва, г. Зеленоград, корп. 528, ком. 17"
  }
}
```

Идентификаторы передаются строками, чтобы сохранить ведущие нули. Для ИП поле `ogrn` содержит ОГРНИП, а `address` — регион регистрации. Если статус, дата или адрес отсутствуют, соответствующее поле равно `null`. 

| HTTP | Код | Условие |
| --- | --- | --- |
| 400 | `invalid_inn` | Длина, состав или контрольные цифры ИНН неверны |
| 401 | `unauthorized` | Сервис требует Bearer-токен, а клиент передал неверный токен или пропустил заголовок |
| 404 | `not_found` | Маршрут неизвестен сервис вернул 404 или успешный ответ с пустой записью |
| 405 | `method_not_allowed` | Для ресурса поддерживается GET |
| 502 | `upstream_error` | Ошибка соединения, неожиданный ответ источника, повреждённая карточка или несовпадение ИНН |
| 503 | `service_unavailable` | Отсутствует ключ сервиса |
| 504 | `upstream_timeout` | Таймаут ответа |
| 500 | `internal_error` | Внутренняя ошибка приложения |
